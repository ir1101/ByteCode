You now know all of MiniLang. Here is a complete program that uses most of it: a function, loops, an early return and a list. It finds every prime number up to 50. A prime has exactly two divisors, 1 and itself.

{% call g.example(title="Primes up to 50") %} # Is n prime? Try every divisor d with d * d <= n. func is_prime(n) { if n < 2 { return 0; } for d = 2; d * d <= n; d += 1 { if n % d == 0 { return 0; # found a divisor: not prime } } return 1; } primes = []; for n = 1; n <= 50; n += 1 { if is_prime(n) { append(primes, n); } } print primes; print len(primes); {% endcall %}

How to read it

  1. is_prime answers one small question, so the main loop reads almost like English: "if n is prime, add it to the list".
  2. It only tries divisors up to the square root (d * d <= n): if n had a bigger divisor, it would also have a smaller partner, which was already tried.
  3. return 0; inside the loop stops as soon as a divisor turns up, with no need for break.
  4. if is_prime(n) works because 1 counts as true.

Sorting a list

One more classic: insertion sort puts a list in order. It takes each item in turn and slides it left past every bigger item before it, like sorting cards in your hand.

{% call g.example(title="Insertion sort") %} xs = [5, 2, 9, 1, 7]; for i = 1; i < len(xs); i += 1 { key = xs[i]; j = i - 1; while j >= 0 and xs[j] > key { xs[j + 1] = xs[j]; j -= 1; } xs[j + 1] = key; } print xs; {% endcall %}

Notice j >= 0 and xs[j] > key: because and stops early, xs[j] is never read when j has run off the front of the list.

  • Lean on and stopping early to guard a read that could fail.

    A number is perfect when it equals the sum of its divisors smaller than itself: 6 = 1 + 2 + 3. Write a function divisor_sum(n) and use it to print every perfect number below 100. There are two.

    {% call g.hint() %}

    In divisor_sum, loop d from 1 to n / 2 (no divisor smaller than n is bigger than that) and add up every d with n % d == 0. Then loop n from 2 to 99 and print n when divisor_sum(n) == n.

    {% endcall %} {% call g.solution() %} func divisor_sum(n) { total = 0; for d = 1; d <= n / 2; d += 1 { if n % d == 0 { total += d; } } return total; } for n = 2; n < 100; n += 1 { if divisor_sum(n) == n { print n; } } {% endcall %} {% endcall %} {% endblock %}
