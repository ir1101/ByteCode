Counting loops have three parts: a start, a condition, and a step. A for loop puts all three on one line, separated by semicolons:

{% call g.example() %} for i = 1; i <= 5; i += 1 { print i * i; } {% endcall %}

That's exactly the same as this while loop, just tidier:

i = 1;              # start
while i <= 5 {      # condition
    print i * i;
    i += 1;         # step, after the block each time
}

You can count in any direction, by any step:

{% call g.example() %} for n = 10; n > 0; n -= 3 { print n; } {% endcall %}

continue and break

  • continue; skips the rest of this pass and moves on to the next one (in a for loop, the step still happens).
  • break; leaves the loop straight away.
{% call g.example() %} for i = 1; i <= 10; i += 1 { if i % 2 == 0 { continue; } if i > 7 { break; } print i; } {% endcall %}

Even numbers are skipped, and the loop stops when it reaches 9.

Loops inside loops

A loop's block can hold another loop. The inner loop runs completely for every pass of the outer one:

{% call g.example() %} for row = 1; row <= 3; row += 1 { for col = 1; col <= 3; col += 1 { print row * col; } } {% endcall %}

Each part of the for line is optional. for ; ; { … } loops forever, so it needs a break to stop it, as in the exercise below.

  • continue; jumps to the next pass, break; leaves the loop.
