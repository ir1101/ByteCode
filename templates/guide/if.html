An if statement runs a block of code only when its condition is true. The block goes between braces { }, and you can put as many statements in it as you like.

{% call g.example() %} temperature = 31; if temperature > 30 { print 1; print temperature - 30; } print 0; {% endcall %}

The first two prints only happen because 31 > 30. The last one is outside the braces, so it always runs. Change the temperature to 25 and run it again.

else

else gives the other branch: exactly one of the two blocks runs.

{% call g.example() %} n = 7; if n % 2 == 0 { print 0; } else { print 1; } {% endcall %}

else if

To choose between more than two options, chain them with else if. MiniLang checks the conditions from the top and runs the first block whose condition is true; else catches everything left over. Since there are no strings, this program turns marks into grade points:

{% call g.example() %} marks = 72; if marks >= 90 { print 4; } else if marks >= 75 { print 3; } else if marks >= 60 { print 2; } else { print 1; } {% endcall %}

Order matters here: 95 is also ≥ 75 and ≥ 60, but only the first matching branch runs.

Small rules

  • The braces are required, even around a single statement.
  • The condition needs no brackets: if x > 0 { is fine, and so is if (x > 0) {.
  • Blocks can contain other if statements. Indenting the inside by four spaces keeps it readable; MiniLang itself ignores spaces.

A classic slip is writing = when you mean ==. MiniLang catches it:

{% call g.example(expect="parse") %} x = 5; if x = 5 { print 1; } {% endcall %} {% call g.remember() %}
  • if condition { … } runs the block only when the condition is true.
  • else runs when it isn't; else if adds more choices, checked top to bottom.
  • Braces are always required. Compare with ==.
