Programs make decisions by asking yes-or-no questions. In MiniLang the answer is a number: 1 means true and 0 means false.

Comparisons

OperatorAsks
==equal? (two equals signs: one = assigns)
!=not equal?
<, >less than? greater than?
<=, >=less than or equal? greater than or equal?
{% call g.example() %} print 3 < 5; print 3 == 5; print 10 != 3; print 7 >= 7; {% endcall %}

and, or, not

Combine questions with words:

  • a and b is true when both are true.
  • a or b is true when at least one is true.
  • not a flips true and false.
{% call g.example() %} age = 15; print age >= 13 and age <= 19; print age < 13 or age > 19; print not (age == 15); {% endcall %}

The first line asks "is this a teenager?". To check that a value is in a range, write both sides out: MiniLang doesn't allow 13 <= age <= 19.

Any number can be a condition

Where MiniLang expects a true-or-false value, 0 counts as false and every other number counts as true. So not 5 is 0, and 2 and 3 is 1.

{% call g.example() %} print not 5; print 2 and 3; print 0 or 0; {% endcall %}

Stopping early

and and or only look at their right side when they need to. If the left side of an and is false, the answer is already false, so the right side never runs. That lets you guard against an error:

{% call g.example() %} d = 0; print d != 0 and 10 / d > 1; {% endcall %}

Without the guard, 10 / d would divide by zero. Swap the two sides of the and and run it to see the difference.
