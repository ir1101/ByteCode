MiniLang works with whole numbers (integers): …, -2, -1, 0, 1, 2, …. There are no decimals, and numbers can be as large as you need, so they never overflow.

The five operators

OperatorMeaningExampleResult
+add7 + 29
-subtract7 - 25
*multiply7 * 214
/divide, dropping any remainder7 / 23
%remainder after dividing7 % 21

Which goes first

Just like in maths, *, / and % happen before + and -. Operators of the same kind go left to right. Brackets change the order.

{% call g.example() %} print 2 + 3 * 4; print (2 + 3) * 4; print 20 - 5 - 3; print 20 - (5 - 3); {% endcall %}

Division and remainder

Because there are no decimals, / gives the whole part of the answer, and % gives what's left over. Together they describe a division completely: 17 sweets shared by 5 children is 3 each, with 2 left over.

{% call g.example() %} print 17 / 5; print 17 % 5; print 10 % 2; print 11 % 2; {% endcall %}

n % 2 is 0 for even numbers and 1 for odd ones, which you'll use a lot. Division rounds toward zero, and the remainder takes the sign of the number being divided:

{% call g.example() %} print -7 / 2; print -7 % 2; print -(3 + 4); print 1000000 * 1000000; {% endcall %}

A minus sign in front of a value makes it negative, as in -(3 + 4). The last line shows that big results are no problem.

Dividing by zero

There's no answer to 5 / 0, so MiniLang stops with a runtime error: an error that happens while the program runs. It names the line, and any output printed before it is kept.

{% call g.example(expect="runtime") %} print 10 / 5; print 10 / 0; print 10 / 2; {% endcall %} {% call g.remember() %}

  • * / % go before + -; use brackets to change the order.
