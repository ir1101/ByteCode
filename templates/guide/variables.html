A variable is a name for a value. You create one by assigning to it with =; there's nothing to declare first. After that, using the name means "the value it holds right now".

{% call g.example() %} width = 6; height = 7; area = width * height; print area; print area + 1; {% endcall %}

Read = as "becomes", not "equals": area = width * height; works out 6 * 7 and stores 42 in area.

Changing a variable

Assigning again replaces the old value. The right-hand side is worked out first, so a variable can use its own current value to make its next one.

{% call g.example() %} score = 10; print score; score = score + 5; print score; score = score * 2; print score; {% endcall %}

Changing a variable "by" something is so common that there are shortcuts: x += 5; means x = x + 5;, and likewise -=, *=, /= and %=.

{% call g.example() %} lives = 3; lives -= 1; print lives; coins = 7; coins *= 10; coins += 5; print coins; {% endcall %}

Names

  • Names use letters, digits and _, and can't start with a digit: total, max_score and p2 are fine.
  • Upper and lower case are different: total and Total are two separate variables.
  • Keywords such as print, if and while can't be used as names.
  • Pick names that say what the value means. slices_each beats s.

Using a name that doesn't exist

If you read a variable that is never assigned anywhere, MiniLang refuses to run the program. When the name looks like a typo, it suggests the one you probably meant:

  • name = value; creates or changes a variable.
  • The right side is worked out first: n = n + 1; adds one to n.
  • += -= *= /= %= are shortcuts for changing a variable.
  • Names are case-sensitive, and using one that never gets a value is an error.
