A list keeps many values in one variable. Write the items between square brackets, separated by commas. print shows the whole list.

{% call g.example() %} primes = [2, 3, 5, 7, 11]; print primes; print primes[0]; print primes[4]; print len(primes); {% endcall %}

Indexes start at 0

primes[0] is the first item, so the last one is at len(primes) - 1, here 4. Asking for an index that doesn't exist is a runtime error:

{% call g.example(expect="runtime") %} xs = [10, 20, 30]; print xs[2]; print xs[3]; {% endcall %}

Changing and growing a list

  • xs[i] = value; replaces one item.
  • append(xs, value); adds an item to the end.
  • len(xs) is how many items there are. [] is an empty list.
{% call g.example() %} squares = []; for i = 1; i <= 5; i += 1 { append(squares, i * i); } squares[0] = 100; print squares; print len(squares); {% endcall %}

Walking through a list

Loop over the indexes from 0 up to, but not including, len(xs):

{% call g.example() %} xs = [4, 8, 15, 16, 23, 42]; total = 0; biggest = xs[0]; for i = 0; i < len(xs); i += 1 { total += xs[i]; if xs[i] > biggest { biggest = xs[i]; } } print total; print biggest; {% endcall %}

Lists inside lists

An item can itself be a list, which gives you a grid. grid[1] is the second row, and grid[1][2] is the third item in it.

{% call g.example() %} grid = [[1, 2, 3], [4, 5, 6]]; print grid[1]; print grid[1][2]; grid[0][0] = 9; print grid; {% endcall %}

Lists are shared, not copied

Assigning a list to another variable doesn't copy it: both names refer to the same list. The same goes for passing a list to a function, which is how a function can change a list it is given.

{% call g.example() %} a = [1, 2, 3]; b = a; b[0] = 99; print a; func clear_first(xs) { xs[0] = 0; } clear_first(a); print b; {% endcall %}

Lists and numbers don't mix

Arithmetic needs numbers, so xs + 1 makes no sense. MiniLang's type checker works out which variables hold lists, and it rejects a mix-up like this before the program even starts:

{% call g.example(expect="type") %} xs = [1, 2, 3]; print xs * 2; {% endcall %}

== and != are the exception: they compare two lists item by item.
