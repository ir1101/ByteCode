A function gives a name to a piece of work so you can use it again and again. You define it once with func, listing its parameters: the values it needs. return sends the answer back.

{% call g.example() %} func square(x) { return x * x; } print square(4); print square(9) - 1; print square(square(2)); {% endcall %}

When you call square(4), the parameter x becomes 4 and the function's block runs. return ends the call, and the call is replaced by the returned value.

More than one parameter

{% call g.example() %} func area(width, height) { return width * height; } func perimeter(width, height) { return 2 * (width + height); } print area(6, 7); print perimeter(6, 7); {% endcall %}
  • Functions are defined at the top level of the program, never inside another block.
  • You can call a function before its definition appears in the file.
  • A call needs exactly as many values as the function has parameters.
  • A function that ends without return, or with a bare return;, gives back 0.
  • A call can be a statement on its own, like show(5);. Its result is then thrown away.

Functions that call themselves

A function can call itself; this is called recursion. It needs a base case that answers without calling again, or it would never stop. The factorial n! = 1 × 2 × … × n is the classic example:

{% call g.example() %} func fact(n) { if n <= 1 { return 1; } return n * fact(n - 1); } print fact(5); print fact(20); {% endcall %}

fact(5) is 5 * fact(4), which is 4 * fact(3), and so on down to fact(1), which is just 1. Open it in the playground and step through it to watch the calls stack up and unwind.

Local and global variables

Parameters, and any variable a function assigns, belong to that one call. They are local, so they can't clash with names outside. A function can read a variable from the main program (a global), but assigning to that name inside the function creates a new local instead. This catches many people out:

{% call g.example() %} count = 0; func bump() { count = count + 1; return count; } print bump(); print count; {% endcall %}

bump() returned 1, but the global count is still 0. MiniLang warns about this "scope trap". To change something in the main program, pass the value in, return the new one, and assign it there:

{% call g.example(title="The fix") %} count = 0; func bump(c) { return c + 1; } count = bump(count); count = bump(count); print count; {% endcall %} {% call g.remember() %}
  • func name(a, b) { … return value; } defines a function; name(1, 2) calls it.
  • Without return, a function gives back 0.
  • Recursion needs a base case.
  • Assigning inside a function makes a local; return values to change the main program.
