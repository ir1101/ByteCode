A MiniLang program is a list of statements, and the computer runs them one after another, from the top down. The simplest statement is print: it works out a value and shows it on its own line.

{% call g.example() %} print 42; print 6 * 7; print 100 - 58; {% endcall %}

Three statements, three lines of output. Notice that print 6 * 7; doesn't show the sum; it shows the answer. MiniLang works out the value first, then prints it.

Every statement ends with a semicolon

The ; tells MiniLang where one statement stops and the next begins. Leaving one out is the most common mistake there is, so it's worth seeing what happens:

{% call g.example(expect="parse") %} print 1 print 2; {% endcall %}

Nothing ran at all. Before running anything, MiniLang reads the whole program to check that it is written correctly, and it reports the line where the ; was expected. Add the missing ; at the end of line 1 and press Run.

Comments

Anything after a #, up to the end of the line, is a comment. MiniLang ignores it completely, so you can leave notes for yourself and for anyone who reads your code.

{% call g.example() %} # This whole line is a comment. print 1; # a comment can also follow a statement # print 2; this line does nothing: it is commented out print 3; {% endcall %}

Putting a # in front of a line is a handy way to switch it off without deleting it.

Only numbers, for now

MiniLang has no text strings: print shows numbers, and later lists of numbers. That keeps the language small, so its whole compiler fits in a few files you can read.
