A while loop repeats its block for as long as its condition stays true. MiniLang checks the condition before every pass, and stops as soon as it is false.

{% call g.example() %} i = 1; while i <= 5 { print i; i += 1; } {% endcall %}

Trace it by hand once: i starts at 1, the condition 1 <= 5 is true, so it prints 1 and i becomes 2. This repeats until i is 6. Then 6 <= 5 is false and the loop ends. If the condition is false from the start, the block never runs at all.

Keeping a running total

A loop often builds up an answer in a variable, like adding up the numbers from 1 to 100:

{% call g.example() %} total = 0; n = 1; while n <= 100 { total += n; n += 1; } print total; {% endcall %}

Two variables do two jobs: n counts, and total collects. Set both up before the loop.

Loops that never end

If nothing in the block ever makes the condition false, the loop runs forever. Here, the line that should move i on is missing. MiniLang lets a program take a large but limited number of steps, then stops it with an error, so a mistake like this can't hang your computer:

{% call g.example(expect="runtime") %} i = 1; total = 0; while i <= 5 { total += i; } print total; {% endcall %}

Add i += 1; inside the loop to fix it.

Off by one

A loop that runs one time too many or too few is called an off-by-one error, and it's very common. When you write a loop, check the first and last pass: does < or <= give the right last value?

  • Something inside the loop must eventually make the condition false.
